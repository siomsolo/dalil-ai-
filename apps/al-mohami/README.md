# المحامي الصغير

مساعد عربي للمعلومات القانونية المغربية العامة، تبدأ نسخته الأولى بالأسئلة العامة حول مدونة الأسرة.

## التقنيات
- React + Vite
- Cloudflare Pages Functions
- Gemini API من جهة الخادم فقط؛ لا يوضع المفتاح في كود الواجهة.

## إعداد Cloudflare Pages
- اربط مستودع GitHub الحالي.
- Root directory: `apps/al-mohami`
- Build command: `npm run build`
- Build output directory: `dist`
- أضف متغيرًا سريًا باسم `GEMINI_API_KEY` في إعدادات المشروع.
- اختياري: أضف `GEMINI_MODEL` إذا أردت تغيير النموذج. القيمة الافتراضية الحالية `gemini-3.8-flash`؛ راجع قائمة النماذج الرسمية قبل التغيير: https://ai.google.dev/gemini-api/docs/models

## التشغيل
```bash
npm install
npm run dev
```

للتجربة المحلية مع وظيفة الخادم، استخدم بيئة Cloudflare Pages محلية (مثل Wrangler) واضبط المتغير السري في البيئة. لا تضع المفتاح داخل ملفات الواجهة أو GitHub.

## حدود النسخة الأولى
- لا تسترجع نصوص القوانين تلقائيًا من بوابة عدالة؛ لذلك لا يجوز الادعاء بأن الإجابة تحققت مباشرة من نص رسمي.
- لا تُخزَّن المحادثات في قاعدة بيانات؛ تبقى في ذاكرة الصفحة أثناء فتحها فقط. السؤال يُرسل إلى خدمة Gemini لتوليد الإجابة.
- لا تطلب من المستخدم بيانات تعريفية أو حساسة.
- قبل الإطلاق العام، اضبط حدود الاستخدام ومكافحة إساءة الاستخدام في Cloudflare، وراقب استهلاك API حتى لا يستنزف الزوار المفتاح.
- يجب مراجعة الإجابات والروابط قبل إطلاق الأداة للجمهور.
- هذه الأداة ليست محاميًا ولا تعوّض استشارة قانونية خاصة.
