Factory controls

Multilingual production with one Gemini project per language. Automatic publishing is enabled only after quality checks.

Use Language:ISO-code. Each language needs a separate Gemini secret.

Gemini creates each product natively in its selected language. Cloudflare Workers AI is reserved for cover artwork. Add one Gemini API key per language as a Cloudflare Pages secret; keys are never displayed here. Production is sequential, not parallel. No daily publishing schedule is used. Production runs sequentially until all configured Gemini free quotas are exhausted. The scheduler automatically retries and resumes production when a key's quota resets; manual resume is optional.

Market opportunities

Production queue

Jobs move through AI drafting, content checks, PDF creation, cover generation and publishing. The saved queue processes one product at a time. When all configured text keys are exhausted, jobs remain safely deferred. The scheduler checks every 5 minutes and automatically resumes when a Gemini quota resets. Cover artwork uses Cloudflare Workers AI first, then a generated SVG fallback if image generation is unavailable.
